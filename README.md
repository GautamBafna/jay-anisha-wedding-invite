# Elegant Invitation Suite

Build a digital wedding invitation website. The page opens with an elegant animation — the envelope opens to reveal the invitation card with the couple's names in calligraphy-style font, the wedding date, and "You are cordially invited." Scrolling down reveals: event details (ceremony and reception times, locations with map links). The design should feel like a luxury printed invitation with subtle animations on scroll. I will share u the wedding details and I HTML file I have made until now. I want u to use real life looking imgs for the design elements like arch, hills, peacocks, elephants etc. I dont want to use emojis or lifeless looking vector elements. Also for the initial envelope too, the design should be of the envelope whose image ive shared with u.
